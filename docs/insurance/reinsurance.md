# Reinsurance

**Core repository:** [`core-insurance-reinsurance`](https://github.com/firefly-oss/core-insurance-reinsurance)

Records for a treaty or facultative placement, the premium ceded from a policy, and a claim recovery notified to that treaty. Placement and the reinsurer's acceptance stay with the reinsurer. Cash movement points at a payment order.

## API

Base path `/api/v1/treaties`.

OpenAPI: [openapi.yml](https://github.com/firefly-oss/core-insurance-reinsurance/blob/main/core-insurance-reinsurance-sdk/src/main/resources/openapi.yml)
